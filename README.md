# CIV Marketplace Android 
 
## Role dans equipe 
Travaillez seulement sur Android interface client vendeur navigation et tests. 
Ne demandez pas acces a cPanel Laravel base de donnees ou cles de production. 
 
## Installer 
1. Installez Android Studio stable avec Android SDK. 
2. Utilisez Embedded JDK et installez SDK 36 si demande. 
3. Utilisez un telephone avec debogage USB ou un emulateur. 
 
## Recuperer le projet 
1. Acceptez invitation GitHub. 
2. Android Studio - Get from VCS - Git. 
3. Collez https://github.com/HAIDARA-INZA/CIV-MARKETPLACE.git 
4. Cliquez Clone puis attendez Gradle. 
5. Cliquez Run pour tester. 
 
## Envoyer son travail 
Avant la tache utilisez git checkout main puis git pull origin main. 
Creez votre branche git checkout -b feature/nom-tache. 
Apres test git add app puis git commit puis git push -u origin feature/nom-tache. 
Creez Pull Request vers main. Ne faites jamais git push origin main. 
 
## Securite 
Ne publiez jamais mots de passe cles API fichier env keystore certificat ou donnees de production.
